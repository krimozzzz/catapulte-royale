# Catapulte Royale II

Jeu de siège en 2D : 64 niveaux, 8 mondes, 4 engins de siège, 21 munitions.

**Jouer :** https://krimozzzz.github.io/catapulte-royale/

## L'installer sur l'écran d'accueil

**iPhone** (iOS 15 ou plus récent)
1. Ouvrir le lien ci-dessus dans **Safari**.
2. Toucher **Partager** (carré avec une flèche vers le haut).
3. Choisir **Sur l'écran d'accueil**, puis **Ajouter**.

**Android** : ouvrir le lien dans Chrome, menu ⋮ → **Installer l'application**.

Le jeu s'ouvre alors en plein écran comme une application, garde la progression
et fonctionne ensuite sans connexion internet.

Ce dépôt ne contient que la version jouable (fichier unique), générée depuis le
projet source par `catapulte/dev/build-web.js`.
